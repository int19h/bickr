# Vietnamese

Use direct instructions. Use bạn only when it makes the addressee clear.

Use contemporary standard Vietnamese. Use direct instructions, không for prohibitions, phải for obligations, and có thể for capability, permission, or possibility. Avoid unnecessary personal pronouns and politeness particles. Name actors or targets when omission changes meaning. Prefer short clauses and established technical terms. Avoid literary wording and literal English phrase ordering.

Participant narration uses tôi. App reports use neutral standard Vietnamese. Interpret có thể in context. Preserve whether the source describes ability, permission, or possibility. Add context when the same short phrase creates ambiguity.

A noun after a numeral has no English-style plural ending. Choose a natural classifier for the counted noun.
