# Korean

Use 하세요 for instructions and 합니다 for descriptions. Use a head noun around a dynamic identifier when a particle depends on its pronunciation.

Use standard written Korean with a consistent neutral polite instructional register, such as 하세요 and 하지 마세요. Use 해야 합니다 for an explicit requirement where necessary. Avoid ceremonial honorifics, chat slang, and translated English nominal chains. Use only pronunciation-independent particles directly after dynamic values. Repeat the actor when an omitted subject can change the instruction's meaning.

Participant narration uses plain written style with 나는 or an omitted subject. App reports use 합니다. Dynamic values need a head noun for 은/는, 이/가, 을/를, 와/과, or (으)로. Fixed identifiers can take a known correct particle outside the token.

Choose a natural counter for each noun. Use 명 for people and 개 for objects when those counters fit.
