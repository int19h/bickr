# French

Use the vous imperative consistently.

Use neutral standard French. Preserve explicit addressed obligation with vous devez and prohibition with ne ... pas around the verb. Do not omit negation. Avoid literary tenses, bureaucratic nominalization, and conversational slang. Use ordinary technical vocabulary and natural articles. Keep identifiers intact.

Participant narration uses je and neutral predicates. Avoid gendered predicates about an unknown speaker. App reports use neutral standard French. Keep the full ne ... pas negation. Keep protected code punctuation unchanged.

The one category includes 0. The many category includes large round counts. Count parameters render as ASCII digits. A category does not insert the words million or milliard. Use de where the written numeral construction requires it. A many variant can match other when the numeral consists entirely of digits.
