# German

Use the Sie imperative consistently.

Use neutral standard German. Use müssen for positive obligations. Use nicht with the imperative for a negative command. Use dürfen nicht for prohibitions. A data rule can prohibit an invalid value. Prefer short main clauses over long verb-final subordinate chains. Break large noun compounds when needed for clarity. Avoid bureaucratic passive voice, ornate vocabulary, and unnecessary English loanwords.

Participant narration uses ich. App reports use neutral standard German. Addressed positive obligations use Sie müssen. Use Darf nicht leer sein for a required nonempty value. Never use muss nicht to mean must not.
