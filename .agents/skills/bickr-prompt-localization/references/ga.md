# Irish

Use a consistent singular imperative in standard Irish. Treat Irish translations as best effort and record unresolved language questions.

Use contemporary standard Irish under An Caighdeán Oifigiúil. Use natural imperative and verbal-noun constructions with a consistent register. Preserve obligation with caithfidh tú or ní mór duit and prohibition with ná in commands. Use established technical terminology where it is clear, with a short explanation when necessary. Avoid literal English word order, invented calques, and literary archaisms. Review mutations, prepositional pronouns, agreement, and technical meaning independently. Mark unresolved terminology as a review gap instead of asserting certainty.


Participant narration and app reports use neutral standard Irish. Never lenite, eclipse, or prefix letters on a protected identifier. Use a head noun instead. Irish needs explicit catalog patterns for lists and relative time. In the current Workers runtime, Intl.ListFormat and Intl.RelativeTimeFormat fall back to English for Irish. Intl.PluralRules supports Irish. Bickr uses explicit Irish catalog patterns and rejects missing entries.

Review noun forms and mutations after numerals. They also apply after written digits. If a form remains uncertain, use a neutral count label and record the uncertainty.

Use a whole native phrase for relative time. Make sure that its numeral rules fit the actual phrase, not only its plural category. Distinguish an hour from an occurrence when using uair. Use uair an chloig for an unambiguous counted hour.

Consult the [official grammar](https://data.oireachtas.ie/ie/oireachtas/caighdeanOifigiul/2017/2017-08-03_an-caighdean-oifigiuil-2017_en.pdf) and [Irish relative-time data](https://github.com/unicode-org/cldr-json/blob/main/cldr-json/cldr-dates-full/main/ga/dateFields.json) when reviewing number forms.

For first-person statements about a needed action, use the established is gá dom construction when it fits the sentence. Do not map English modal words to Irish words mechanically. Caithfidh and ní mór can also express practical need. The [official need entry](https://www.focloir.ie/en/dictionary/ei/need) gives these constructions in context.
