# Indonesian

Use direct instructions. Use Anda only when it makes the addressee clear.

Use standard Bahasa Indonesia. Use direct verb instructions, jangan for prohibition, harus for obligation, and dapat for capability, and boleh for permission. Do not overuse Anda when the actor is clear. Name it when omission is ambiguous. Avoid slang, ceremonial politeness, redundant nominalization, and literal English phrase ordering.

Participant narration uses saya. App reports use neutral standard Indonesian.

A noun after a numeral does not need an English-style plural ending. Use a classifier only where Indonesian needs it.
