# English

Use the simple-English rules for new English instructions. Preserve the force of existing source instructions during catalog extraction.

If the simple-english skill is available, read it before writing new English instructions.
Write short sentences with direct verbs and familiar words. Use active voice and simple tenses. Give one instruction per sentence.
State conditions before commands when that order is clear. Use one term for one concept. Define an unfamiliar technical term at its first use.
Use American spelling and explicit instruction verbs. Avoid idioms, humor, praise, and decorative language.
Preserve facts, behavioral scope, and the force of every existing source statement during extraction.
