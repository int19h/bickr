# Japanese

Use 〜してください for instructions and です／ます for descriptions.

Use standard written Japanese with a consistent neutral instructional register. Prefer concise 〜してください instructions and 〜しないでください prohibitions. Use 〜する必要があります for an explicit requirement when its force matters. Avoid honorific elevation, casual speech, indirect requests, and excessive nominalization. State the topic or actor when an omitted subject creates ambiguity. Keep Latin tool identifiers intact. Use Japanese punctuation and sentence boundaries.

Participant narration uses plain written form with 私 when a subject is needed. App reports use です／ます. Keep the specified polite instructional register for direct instructions.

Choose a natural counter for each noun. Do not apply one generic English count pattern to every noun.
